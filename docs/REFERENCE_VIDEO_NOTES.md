# Reference Video — Design Notes

**Source:** the 39.5-second vertical video uploaded with the request. It shows a birthday microsite displayed on a laptop.

## What is visible in the reference

- Dark near-black/navy canvas with small white star-like points.
- Pink/magenta vertical code-like lines used for an animated countdown/reveal.
- Large bright-pink birthday typography with a recipient name and heart.
- A cute illustrated birthday/cake/character interlude.
- A warm cream greeting panel on the dark background.
- Individual photographs presented in softly framed cards.
- Multiple photo cards arranged into a heart-shaped final composition.

## Approximate sequence in the reel

The exact animation timings are not a requirement; the following sequence is based on the visible sampled frames:

1. Opening/build-up with the countdown over magenta vertical lines.
2. “Happy Birthday” and recipient-name reveal.
3. A playful birthday character/cake moment.
4. Greeting card and photo memories.
5. Final photo collage arranged as a heart.

## Adaptation for this project

- Replace the original recipient with **Vaatsal Bhai**.
- Replace any romantic/partner-style message with friendly birthday language from the six friends.
- Use only the group's own supplied photographs.
- Keep the same broad visual progression while creating original layout, code, copy, and illustration details.
